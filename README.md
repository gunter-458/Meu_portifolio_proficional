## Sobre `On-Life`
# OnLife — Equilíbrio no mundo digital

O **OnLife** é um projeto acadêmico desenvolvido com o objetivo de conscientizar sobre o uso excessivo da internet e seus possíveis impactos na saúde mental e no bem-estar.

O site reúne informações, orientações e ferramentas interativas para incentivar uma relação mais saudável e equilibrada com a tecnologia.

## Páginas do site

O OnLife possui páginas com diferentes conteúdos e funcionalidades:

- **Início (`index.html`):** apresenta o projeto e oferece acesso às demais páginas.
- **Impacto (`impacto.html`):** aborda os possíveis impactos do uso excessivo da internet na saúde mental, no sono, nas relações sociais e na concentração.
- **Recupere-se (`recupere_se.html`):** apresenta orientações para desenvolver hábitos digitais mais saudáveis.
- **Relatório (`relatorio.html`):** reúne informações e dados sobre o tema, utilizando gráficos para facilitar a visualização.
- **Calculadora de Tempo (`calculadora_tempo.html`):** permite calcular o tempo gasto nas telas e visualizar projeções desse período.
- **Relógio de Foco (`relogio_foco.html`):** oferece um temporizador para auxiliar na concentração e na organização do tempo.
- **Sobre (`sobre.html`):** apresenta a proposta, os objetivos e as informações gerais do projeto.

## Tecnologias utilizadas

As principais tecnologias e ferramentas utilizadas no desenvolvimento foram:

- **HTML5:** estruturação das páginas.
- **CSS3:** personalização e organização visual.
- **JavaScript:** funcionalidades e interatividade.
- **Bootstrap 5.3.8:** componentes e organização responsiva.
- **Chart.js:** criação dos gráficos apresentados na página de relatório.

## Como baixar o projeto

Para obter uma cópia do projeto pelo GitHub:

1. Acesse o repositório do OnLife.
2. Clique no botão **Code**.
3. Selecione a opção **Download ZIP**.
4. Após o download, extraia o arquivo ZIP para uma pasta do computador.
5. Abra o Visual Studio Code.
6. Clique em **File > Open Folder** e selecione a pasta extraída do projeto.

## Como executar o site

O projeto utiliza HTML, CSS e JavaScript, portanto não é necessário instalar dependências com npm para visualizar as páginas.

### Opção 1 — Abrir pelo navegador

1. Entre na pasta do projeto.
2. Localize o arquivo `index.html`.
3. Clique duas vezes nele para abrir no navegador.

### Opção 2 — Utilizar o Live Server

1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão **Live Server**, caso ainda não esteja instalada.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito dentro do código.
5. Selecione **Open with Live Server**.

O site será aberto no navegador. Ao salvar alterações nos arquivos, o Live Server atualizará a página automaticamente.

**Importante:** para que os caminhos dos arquivos funcionem corretamente, abra a pasta principal do projeto no Visual Studio Code, e não apenas a pasta `pages`.
